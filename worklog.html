云同步

多台设备通过互联网共用一份数据，按记录修改时间自动合并
同步方式
数据分两个文件：记录文件（很小，每 0.5 秒检查一次）与照片文件（较大，仅照片变化时上传）。其他设备填同一个 Token 即可拿到相同数据。
想「不换网址换 Token」：把本文件与 sync-config.json 放在同一目录（例如 GitHub Pages），以后只改 sync-config.json 里的 token，页面地址不变；未部署该文件时使用内置 Token。
注意：Token 已内置在本页文件中，请勿将此文件转发给他人；若已外传，请立即到 GitHub 删除该 Token 并重新生成，再填入本页。
接口需支持浏览器跨域（CORS）。坚果云等 WebDAV 服务若被浏览器拦截，请改用 GitHub 方式。上传内容为整份 JSON 快照。
尚未配置云同步
同步采用「按记录合并」：同一记录取修改时间较新的版本，删除会作为标记同步到其他设备；照片随记录一起同步，数据量较大时建议定期导出备份。
